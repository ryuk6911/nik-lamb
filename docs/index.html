📦 Installation

1

Download & Unzip

Click the download button above. Extract the ZIP file — you'll get a folder called nik-lamb.

2

Open Chrome Extensions

In Chrome, go to chrome://extensions in the address bar. Turn ON "Developer mode" using the toggle in the top-right corner.

3

Load the Extension

Click "Load unpacked" and select the unzipped nik-lamb folder. The ⚡ icon should appear in your Chrome toolbar.

4

Open the Target Page & Set Up

Navigate to the target page. You'll see a floating ⚡ Nik-lamb panel. Click ⚙️ Setup to configure the elements, then hit ⚡ ARM to start.

🧪 Feedback

  • Speed: How fast does it react? Check the Activity Log for timestamps.
  • Setup: Did the point-and-click element selection work correctly?
  • Dialogs: Did it handle confirmation popups automatically?
  • Errors: Open DevTools (F12) → Console — screenshot any errors.
  • Screenshots: Activity Log panel + DevTools console.

🔄 Updating

1

Re-download

Come back to this page and download the ZIP again.

2

Replace & Reload

Extract over the old folder. Go to chrome://extensions and click the 🔄 reload button on the extension card.

ℹ️ Note

This extension runs entirely in your browser. No data is sent to any external server.
