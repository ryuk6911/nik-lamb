📦 Installation Steps

1

Download & Unzip

Click the download button above. Extract the ZIP file — you'll get a folder called ireps-auto-bidder.

2

Open Chrome Extensions

In Chrome, go to chrome://extensions in the address bar. Turn ON "Developer mode" using the toggle in the top-right corner.

3

Load the Extension

Click "Load unpacked" and select the unzipped ireps-auto-bidder folder. The ⚡ icon should appear in your Chrome toolbar.

4

Go to IREPS & Set Up

Navigate to your IREPS auction page. You'll see a floating ⚡ Auto Bidder panel. Click ⚙️ Setup and point-and-click on the bid elements, then hit ⚡ ARM.

🧪 Testing — What to Report Back

  • Speed: How fast does it react? Check the Activity Log for [via network] vs [via poll]
  • Network URLs: What shows up in 📡 Network intercept messages in the log?
  • Confirmation dialogs: Does it auto-click OK/Confirm after bidding?
  • Selectors: Did point-and-click setup pick the correct elements?
  • Errors: Open DevTools (F12) → Console → filter for [IREPS-Bot]
  • Screenshots: Activity Log panel + DevTools console after a few bid cycles

🔄 Updating to a New Version

1

Re-download

Come back to this page and download the ZIP again.

2

Replace & Reload

Extract over the old folder. Go to chrome://extensions and click the 🔄 reload button on the extension card. Your saved config will persist.

⚠️ Important

This is a personal productivity tool. You must have a valid DSC to log in to IREPS. The extension runs entirely in your browser — no data is sent to any external server.
